# KioskHelper

A collection of utility scripts for Unity kiosk applications.

I decided to publish a bunch of stuff I've used over the years to help
in building kiosk type games and applications. Some of these like the
Corner Clicker prefab/script were used in literally every kiosk I
ever produced. I'll be adding more as I can - keyboard coming soon.

## Dependencies

KioskHelper requires:

- TextMeshPro
- Unity UI
- Input System
- DOTween (standard version or Pro)

DOTween must be installed separately.
